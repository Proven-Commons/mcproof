# Bidirectional Cross-Pollination Ledger (`mcproof` v0.2, `soko`, and Collaborator Repos)

This ledger records every formal theorem, certificate gate, and closed-loop repair mechanism transferred between `Proven-Commons/mcproof`, `ahrazzle/soko`, and collaborator formal-verification repositories. It pairs exact file paths, symbol names, and pull requests across repositories so verifiers can audit each dependency without guessing. Engineers extending `mde:formal-verification` or `mde:soko-eval` use this page to keep domain-general kernels separate from specialist search harnesses.

## Architectural Boundary

`Proven-Commons/mcproof` owns the domain-general Formal Verification MDE (`mde:formal-verification`), including the stock-`Init` Lean `v4.35.0` kernel library, label-free Plane 1 retrieval, multi-turn repair loop, and `F-01` through `F-08` certificate auditors (`https://github.com/Proven-Commons/mcproof/issues/5`). `ahrazzle/soko` owns the specialist state-space search harness (`mde:soko-eval`), dual transition engines, and frontier lower-bound certificates (`https://github.com/ahrazzle/soko/issues/53`).

## What is not proved

- `Mcproof.TransitionBounds` proves soundness and `1`-step consistency conditional on a domain's transition projection, action dual load, or cut-capacity hypotheses. Verifying that a concrete C++, Rust, or Python transition table satisfies those hypotheses requires complete finite-graph enumeration or a mechanized transition-semantics embedding.
- Label-free inference stopping (`default_inference_oracle`) certifies syntax, kernel type-checking, static exact-math rules, and prompt-visible claim hygiene, whereas hidden test-case completeness on Family `B` is measured post-hoc by `eval_grader_fn`.

## What you must trust

- Lean `v4.35.0` and all five external kernels configured in `lean/comparator.json` (`leanchecker`, `lean4lean`, `nanoda`, `con-leche`, `con-ron`).
- Subprocess process-group isolation, stripped environment variables, and AST import guards inside `run_restricted_sandbox_cell`, together with SHA-256 manifest verification in `mcproof lineage --verify`.
